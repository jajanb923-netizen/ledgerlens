How the hybrid AI works

  1. On-device first. Firebase AI Logic (InferenceMode.PREFER_ON_DEVICE) tries Gemini Nano 4 in Chrome. Summaries of your ledger run locally — fast, private, free.
  2. Cloud fallback. If no on-device model is available, the same call falls back to gemini-3.5-flash-lite in the cloud. Every answer shows an On device / Cloud / Local badge so you always know where it was computed.
  3. Offline-first data. All transactions live in your browser (localStorage). No account, no server, no cost. Export a CSV anytime.
  4. Free to run. Text inference with Firebase AI Logic is free within usage limits; the app also works fully without any Firebase project, using its built-in local analyser.
